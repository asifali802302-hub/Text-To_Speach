# Text-to-Speech Application

A web-based Text-to-Speech application that converts written text into natural-sounding speech.

## Features

- Convert text into speech
- Support for multiple languages
- Male and female voice options
- Character count
- Word count
- Maximum 5000 characters
- Play generated audio
- Download generated audio as MP3
- Clear text with one click
- Backend health check
- Input validation
- Error handling
- Responsive user interface

## Supported Languages

- English
- Hindi
- Gujarati
- Marathi
- Spanish
- French
- German

Each supported language provides male and female voice options.
